ILIAS connector

An optional browser extension for Edge and Chrome on a computer. Version 0.2.0.

The connector looks for file links on the HSLU ILIAS pages you can open while signed in, and hands the ones you choose to Booklyn. It never asks for your password, and nothing is uploaded to Booklyn’s servers: files go straight from ILIAS into your own browser storage.

Step 1. Download the connector.

Download ilias-connector.zip

Install (about two minutes)

  1. Unzip it. Right-click the file and choose Extract all. Keep the folder somewhere permanent, for example Documents. If you delete it, the extension stops working.
  2. Open the extensions page. In Edge go to edge://extensions, in Chrome go to chrome://extensions.
  3. Turn on Developer mode. The switch is in the left column in Edge and at the top right in Chrome.
  4. Load the folder. Press Load unpacked and pick the booklyn-ilias-connector folder you unzipped.
  5. Sign in to ILIAS in the same browser, then reload any ILIAS tab that was already open.
  6. Open Booklyn, go to Port and press Check ILIAS. Choose the files you want and press Add to Port.

Good to know

  • It works only on a computer. Phone browsers do not run this kind of extension, so add files by hand there.
  • Files over 12 MB must be added by hand.
  • Updating: download the new zip, replace the folder contents and press the reload icon on the extensions page.
  • It only reads elearning.hslu.ch and the Booklyn page. You can check this in manifest.json inside the zip.
  • Use it only as HSLU allows. See the terms.

One-click install, later

A listing in the Microsoft Edge Add-ons store and the Chrome Web Store would make installation a single click. That is planned once the connector has been tested by more students.
